2. MUST HAVE ITEMS
================================================================
[x] Langfuse streaming traces prefer structured `responseOutput` over reparsing raw `responseText`.
    - emit-proxy-trace.ts: EmitProxyLangfuseTraceData gains optional `responseOutput?: unknown`.
    - trace-proxy-request.ts: TraceContext gains `responseOutput?`, buildResponseOutput()
      returns ctx.responseOutput verbatim when defined; falls back to responseText parsing.

[x] All 4 payload families implemented in stream-output-normalizer.ts:
    - responses-codex: normalizeResponses (terminal-object-first via response.completed.response;
      synthesis from response.created + output_text.done/reasoning_summary_text.done/reasoning_summary_part.done
      + output_text.delta fallback). Matches codex/types/response.ts shape.
    - anthropic: normalizeAnthropic (message_start base, per-block assembly from content_block_start/
      delta/stop, tool_use input_json_delta merge, message_delta stop_reason/stop_sequence/usage,
      message_stop terminal gate).
    - openai-chat: normalizeOpenAIChat / normalizeOpenAIChatFromObjects (per-choice role/content merge,
      last non-null finish_reason). Matches codex/types/compatible.ts ChatCompletionResponse.
    - gemini: normalizeGeminiFromEvents / normalizeGeminiFromObjects (latest complete object with
      candidates preferred; otherwise synthesize from merged text parts + latest usageMetadata/
      modelVersion/responseId/promptFeedback/finishReason).

[x] Incomplete/error streams fall back: normalizer contract (lines 39-48) explicitly refuses to
    fabricate; returns null when terminal evidence is missing. Verified in normalizeResponses
    (returns null when no `created` event, no done/delta text, or response.failed/incomplete).
    Caller (response-handler.ts:2778-2780) passes `undefined` when streamFamily is null or
    normalization returns null, preserving legacy raw/error behavior.

[x] sseEventCount, usageMetrics, costUsd, costBreakdown, statusCode, durationMs, error fields
    remain on both emit sites (response-handler.ts:2121-2128 Gemini, 2775-2789 general).

[x] Raw session response storage / snapshots / SSE dashboard display unchanged:
    - response-handler.ts Gemini site: allContent still used for
      SessionManager.storeSessionResponsePhaseSnapshot (line 2083),
      finalizeDeferredStreamingFinalizationIfNeeded (line 2102),
      finalizeRequestStats (line 2110). Only the Langfuse emit (line 2121) receives responseOutput.
    - General site: same pattern — chunks.join("") persistence unchanged; only the Langfuse emit
      (lines 2778-2780) receives responseOutput.
